# OS de manutenção executadas

Envie aqui o arquivo novo (botão "Add file" → "Upload files", ou pelo menu "Atualizar bases" do site).

A base OS_STATUS_Executadas em .zip (com o .txt separado por ";" dentro). O .txt sozinho passa do limite de envio do GitHub (25 MB pelo navegador). Entram as OS de manutenção corretiva (MC) e preventiva (MP); inspeção, manobra e construção ficam de fora. Cada OS vai para o ativo dela no mapa (o poste da ESTRUTURA; sem ele, o trafo ou a chave da OS) e aparece no card Manutenção.

O site se atualiza sozinho uns 5 minutos depois do envio (acompanhe na aba Actions). Se der erro, nada é publicado.

Atenção: este repositório é público; o arquivo enviado fica visível.
